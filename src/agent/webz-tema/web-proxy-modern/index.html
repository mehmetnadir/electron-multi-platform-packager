Kütüphaneme Ekle Ana ekrana kısayol ekle, tek dokunuşla aç.

Kısayol Ekle

Chrome / Edge (Masaüstü)

  1. Adres çubuğunun sağındaki indirme / uygulama ikonuna tıkla
  2. Veya ⋮ menü → "Uygulamayı Yükle" / "Install app" seçeneğini seç
  3. Masaüstünde yayınevi adıyla kısayol oluşur

Safari (iPhone / iPad)

  1. Alttaki Paylaş butonuna bas
  2. "Ana Ekrana Ekle" seçeneğini seç
  3. Ana ekrana ikon olarak eklenir

Android Chrome

  1. ⋮ menü → "Ana ekrana ekle"
  2. Veya tarayıcı "Uygulamayı yükle" banner'ını gösterir
